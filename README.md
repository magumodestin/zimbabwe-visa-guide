# Zimbabwe Visa Guide

A simple front-end web page that shows where a Zimbabwean passport holder can travel and what entry requirement applies for each destination: visa free, visa on arrival, eTA, eVisa (apply online), or visa required.

Built with plain HTML, CSS and JavaScript. No frameworks, no build step.

## Features

- Lists 198 destinations, each placed in one entry category
- A colour bar at the top shows the share of destinations in each category, and clicking a section filters the list
- Filter buttons with a live count for each category
- "Visa type" dropdown (synced with the buttons and colour bar) to show only one category, such as eVisa
- Search box that works together with the filters
- Country flags and country names generated from ISO codes
- Responsive layout for phones, tablets and desktops

## Categories

| Category | Meaning |
|---|---|
| Visa free access | No visa needed to enter (stay limits vary) |
| Visa on arrival | Get the visa at the airport or border |
| eTA | Electronic travel authorisation before you travel |
| Visa online (eVisa) | Apply for the visa online before you travel |
| Visa required | Apply at an embassy or consulate in advance |

## Run locally

1. Download or clone the repository.
2. Open `index.html` in your browser, or place the folder in your local server directory (for example `htdocs` in XAMPP) and visit it through `localhost`.

An internet connection is needed to load the flags (flagcdn.com) and the font (Google Fonts).

## Updating the data

All country data lives at the top of `script.js` in the `categories` array. Each country is stored as a two-letter ISO code, and the name is generated by the browser:

```js
{ id: "free", title: "Visa free access", color: "var(--free)", codes: ["AO", "BW", "ZA"] }
```

To move a country to another category, remove its code from one list and add it to another. The counts, bar and filters update automatically.

## Data source

The requirements come from the open [Passport Index dataset](https://github.com/ilyankou/passport-index-dataset). It is a snapshot and may not reflect recent changes. Visa rules change often, so always confirm with the destination's official immigration website or embassy before you travel.

## Colours

Category colours are CSS variables in the `:root` block of `style.css`, so you can restyle the page by editing a few values.
